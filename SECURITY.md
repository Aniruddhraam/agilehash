# Security Policy

## Supported Versions

The following versions of `agilehash` currently receive security updates and patch releases via Pull Requests:

| Version | Supported          |
| ------- | ------------------ |
| v1.0.0  | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability or algorithmic defect in `agilehash`, please do **not** open a public GitHub issue.

Instead, please report it privately for secure disclosure by emailing:

[aniruddhraam07@gmail.com](mailto:aniruddhraam07@gmail.com)

### Disclosure Guidelines
- Include a description of the vulnerability and its potential impact.
- Provide step-by-step instructions or a minimal Go proof-of-concept (PoC) to reproduce the behavior.
- Provide any suggested fixes or patch implementations if available.

### Response Timeline
- **Acknowledgment**: Reports will be acknowledged within 48 hours.
- **Fix & Patch**: Upon confirmation, a security patch PR will be prepared and merged into `main` followed by a new patch release.
